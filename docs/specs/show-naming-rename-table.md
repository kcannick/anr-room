# Show naming by close date — proposed name changes

Status: PROPOSAL, nothing applied. Built 2026-10-03 from a read-only list of production sessions.
Replaces the numbering proposal (option 4) of 2026-09-30.

## The rule (operator, 2026-10-03)

A set of records is named for **the day it closes**. It opens the day before, closes on the
named date, and is posted the day after.

| | Example |
|---|---|
| Opens | Saturday October 3rd, 3:00 PM ET |
| Closes | Sunday October 4th, 3:00 PM ET |
| Posted | Monday October 5th |
| Internal session name | **Daily Drop - Oct 4, 2026** |
| Name in copy | **October 4th** |
| Public title | **Makin' It Daily Countdown** / **October 4th Results** |

Every surface prints this one date. Other dates (opens, closes, airs) appear only as times
with a label, e.g. "closes tomorrow at 3:00 PM".

**Internal session names carry the session TYPE and the date** (operator, 2026-10-03), because
daily drops share the console with Live Reviews, Takeovers, Tournaments, Versus competitions:
`Daily Drop - Oct 4, 2026`, `Live Review - Jul 3, 2026`. A one-off event keeps its own title as
the type (`ATL Record Pool - Jul 26, 2026`).

**BETA sessions are numbered: "Show N — <internal name>"**, Show 1 – Show 75 in date order. A
daily set's date is its close day; a live session's date is the day it ran (already in its
name), not the past-midnight time of its last round. Sets from Series 1 onward carry no number.
