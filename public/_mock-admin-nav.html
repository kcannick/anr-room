The problem

The console grew one screen at a time, and each new screen got a button wherever there was room. Today there are two different menus, and which one you see depends on where you came from.

Today

  1. Two menus. Daily, Weekly and Tournaments have a 5-button switch at the top. The room list has a different row of 10 buttons. Charts, Users, Series, Analytics and Sidebet are only in the second one.
  2. "Live show" opens the room list, and the room list is where Charts, Users and Analytics live. You go "into the live show" to look up an A&R.
  3. Every back button says "← My rooms", but the console opens on A&R Daily, not rooms. Back takes you somewhere you weren't.
  4. Platform is a drawer of 9 unrelated cards: banners, the daily schedule, Asana, Brevo, the contact backfill, the mass message, the SMS test.
  5. No addresses. Refresh or the browser's Back button does not keep you on the page you were on.
  6. Log out is in three different places.

Proposed

  1. One sidebar, always on screen, the same on every page. Every screen is in it, so you never need to remember which page has the button.
  2. One name per thing: Daily Drops, Live Sessions, Tournaments, Top Picks. The sidebar, page titles and buttons all use the same four.
  3. Four groups by job: Run the show · Results · A&Rs & artists · Settings.
  4. Platform is split up by what each card is for: the schedule is a setting, the mass message is about A&Rs, Brevo and Asana are contact lists.
  5. No back buttons. The sidebar shows where you are; inside a session, a line at the top reads "Live Sessions › Session name".
  6. Every page has an address (/admin#weekly), so refresh, Back and bookmarks work.
  7. Problems show up in the sidebar (a red dot on Connections when the submission system is failing), not only on the page you happen to open.
