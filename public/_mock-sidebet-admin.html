3 · Load the songs (CSV)
Row order is load-bearing. When two played songs are picked by the same number of entrants, CSV row order breaks the tie — so it's fixed before any entry exists and can't be argued with afterward. The loader shows row numbers for that reason, and says so on screen rather than burying it in the spec.

4 · Settle
Songs are pre-ticked from the A&R Wars Versus rounds — every matchup is a two-song binary round, so the 18 fall out with no extra work on show night. The host confirms or corrects, because a swapped song or an off-script matchup has to be fixable. Settle refuses to run at anything other than exactly 18: a miscount doesn't error on its own, it just quietly crowns the wrong person. Try unticking one.

Ready to settle.
Settling computes the winner, writes every entry's score, and unhides pick counts. Until then no aggregate is readable anywhere — the tiebreak ranking is built from the entries themselves, so a visible "340 people picked this" would make copying the crowd the winning move. Settle can be re-run while the iteration is closed, so a corrected checklist produces a corrected result.
5 · Results (after settle)
Most right wins; order breaks ties; earliest final edit breaks what's left. The order distance column is only meaningful inside a tie group, so it's greyed where nothing is tied.

Constraints this screen enforces
The CSV can't be replaced once entries exist. Every pick points at a pack_song row; re-uploading would repoint or orphan 147 people's selections. After the first entry the loader offers per-row edits (fix a typo) and nothing else. Get the CSV right before you open the iteration — the mockup says this in the loader, not just here.

The sponsor banner is the existing banner system. packs.banner_id → the banners table, same library and uploader as room banners, served by /api/banner/image. No new table and no second image path.

Cut-off before the Wars date, always. Enforced server-side too, not only in this form.

Picks-to-predict is per iteration. July ran 14. Nothing in the code hardcodes 18.
