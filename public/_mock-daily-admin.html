Fixing a broken link mid-window

The single most operationally important surface here. A dead link at 12:05 PM is a dead record for the next 21 hours — nobody is watching the way a host watches a live show, and the fix cannot round-trip through a CMS. So the console fixes it immediately and Drupal is where non-urgent corrections are made and re-pushed. Descriptive fields only: this dialog has never been able to touch votes, points or status.

After the tally, before the send

A missing drop is an incident, not an empty state. If Drupal has not pushed, the site is back to exactly the failure this build exists to fix — an A&R opens the app and there is nothing to do. It reads as an alarm, not as a shrug.
