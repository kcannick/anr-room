How the system works

  1. The countdown blocks are the series' own mark. Each rank slide counts from its own rank down to #1: #16 shows 16 → 01, #3 shows 03 02 01, #1 shows one gold block. No rank slide shows how many records there were, so #16 never reads as last.
  2. The rank is the biggest thing on the slide, set in Space Mono like every number in the brand. Then the title, then the artist and handle. The submit link sits under a rule as one button, so it never competes with the rank.
  3. #1 is the gold version of the same layout: gold numeral, gold tick, a soft gold glow, and the TOP TRACK OF THE DAY block between the rank and the title. Gold only means first place and money, so it also appears on the $1,000 and nowhere else.
  4. The cover and both closing slides carry the large 13° green cut. Each closing slide has one ask: the first thanks the A&R Team and recruits more (makinitmag.com/ANR), the second sends artists to submit. Rank slides use the button instead, because the cut would run into a long title.
  5. Long copy fits automatically. The title steps down in size to stay within two lines, the artist name stays on one line, and the handle shrinks to the width. Everything stays at least 80px from every edge.
  6. The date is the day the post goes up. The cover drops "Today's Top N": the date says which day, and "Ranked by the Makin' It A&R Team" moves up into its place. Two-digit ranks stay at full size.
  7. Name: this is the Makin' It Daily Countdown. HOT 100 is kept for the monthly countdown post.
