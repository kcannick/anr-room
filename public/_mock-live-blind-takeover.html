Blind results and Takeover

Blind results: rounds are scored as usual, but nobody sees an average until the host reveals them all at the end, so earlier results cannot sway later votes. The session goes Live (rating) → Closed (voting over, nothing shown) → Published (the host presses Reveal). Takeover: one artist set once; each record needs only a title.
